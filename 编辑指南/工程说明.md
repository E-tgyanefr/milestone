## 2. 模式更改：加/改一个音游模式

### 2.1 完整链路（新增玩法时必须走通）

1. **注册**：源码\CoreUtil\ModeSystem.cs 的 ModeInfo 表加一行（参考既有项目）：Mode=枚举（GameMode）、Id=唯一短名（如 mania）、Display=显示名、Keys=默认键数、Tracked/Adjustable、KeyHint、格式说明。
2. **格式解析**：源码\CoreUtil\ChartParser* 增加对应扩展名/格式分支（.osu/.aff/.adofai/.txt/.mil/.json 已有各自解析器；新格式=新解析器或扩展 ChartParserExtra）。
3. **渲染**：源码\Play\GamePanel.cs 增加 Draw 函数（参考 DrawMania/DrawPhigros/DrawArcaea/DrawCytus/DrawOsuStandard/DrawIidx/DrawMaimai/DrawAdofaiReal），并在 PaintCore 的分派处接入——同一 PlayLayout 输入（Area/TopY/HitY/Ppm/LaneW…）保证多分辨率自动成立。
4. **判定**：引擎侧 Ruleset 派生（Lane/Line/Ring/Path 四族选一，或自定义），注册到 RulesetFactory；JudgementProfile 档位表加预设（RhythmCore 16 档位之一或新增）。
5. **场/输入**：Playfield 场族（LineField/RingField/…）+ InputCore 命中区（HitZone 矩形/圆/环）。
6. **编辑器**：ChartEditorPanel 的模式分派（有轨/无轨范式；无轨按 RPE 白线+事件；有轨按列式网格）。
7. **示例与校验**：ChartValidator 模式规则 + 示例谱（输出产物\示例内容\Milestone示例\*.mil / 测试格式\）+ EngineChecks 断言。
8. **验证**：见 5.4 标准验收流程（selfcheck/parity/shellshot/还原度对比）。

### 2.2 如何改已有模式（小改）

- **改键数/默认值**：ModeInfo（Keys/Adjustable）+ GamePanel 键数逻辑 + ChartParser 端校验。
- **改判定窗口**：JudgementProfile 预设（引擎\engine\RhythmCore.cs）或运行期 JudgementTracker.SetProfile 热换 + WindowMultiplier（0.25~4 乘算，×1.0 零差异——设置页「判定基准」）。
- **改流速/缩放/方向**：谱面事件（zoom/noteSpeed/scroll，ComputeLayout 求值）+ 布局元素 field.speed（见 文档精选\layout-custom-design.md）。
- **改数值风格**：NoteStyleBook（引擎\engine\NoteStyle.cs）——每模式配色/描边/发光；皮肤 NoteColors 亦可覆盖。

### 2.3 模式预设（EnginePresets，t57）

- 位置：引擎源码\engine\EnginePresets.cs（静态注册表，10 项：mania4/6/8 phigros arcaea cytus osustd iidx maimai adofai）。
- 每项：Id/Display/Field（Lane/Line/Ring/Path）/Keys + 生成示例谱种子（RulesetFactory.BuildSampleChart，音符数/长条/滑星特征可调）。
- 引擎侧闭环验证：引擎源码\engine\EnginePlay --preset <id> --headless（无头跑预设 → ACC/轨迹输出）；ToDocTable() 生成预设表文本。
- 游戏内入口：引擎菜单「AI 演示」等按预设驱动（AiEngine 规则式，不接 LLM）。

## 3. UI 更改：改文字 / 布局 / 主题 / 图标

### 3.0 三条铁律（先读）

1. **文字只改 UiText.cs**（源码\CoreUtil\UiText.cs）——每键带注释「原文出处」，严禁在场景/面板代码里写死用户可见字符串。
2. **布局只改坐标与自适应公式**：所有页面布局由 UiMeasure/UiTheme.Scaled 自适应公式决定，不要写绝对像素当修复——多分辨率（1280×800→4K+DPI）会崩。
3. **每改一处→构建→截图核对**：用 输出产物\bin\Release\net8.0-windows\win-x64\Milestone.exe --shellshot <目录>（引擎壳三页离屏渲染）或 --menushot 快速取证，别纯目测。

- 例：主菜单「▶ 开始游戏」在 UiText.cs:25（MenuPlayGame）；功能按钮 18 项紧随其后；提示行 MenuHint；设置分区/次级页/编辑器文案各区段都有注释索引。
- 改后：引擎壳/引擎演示/parity 基线同源（UiText 常量），改一处全界面生效；**注意 parity-text-baseline.json 基线：若改了作为基线键的文案，parity -1 会报缺——按 5.4 同步基线或选择非基线键。**

### 3.2 改布局（页面元素）

## 4. 引擎改动：Ruleset / 判定 / 渲染 / 引擎工具 CLI

### 4.1 Ruleset（玩法规则族）

- 基类：Ruleset.cs（abstract；ChartContext + 场/输入/判定无头组合）；派生四族：Lane（轨）、Line（线）、Ring（环）、Path（路径）——RulesetFactory 注册。
- 新增玩法：派生 Ruleset → 注册 → EnginePresets 加预设 → EnginePlay --preset 无头闭环验证（无头可跑=规则自洽）。
- 样例种子：RulesetFactory.BuildSampleChart(mode, seed)——音符数/长条/滑星按预设元数据生成，用于演示/测试/编辑器空谱。

### 4.2 判定

- RhythmCore.cs：JudgeTier（档位）/JudgementProfile（任意档位+窗口，16 预设：Arcaea/Phigros/IIDX/Cytus/ADOFAI/mania(OD)…）/MaxWindowMs（乘 WindowMultiplier 0.25~4）/Evaluate。
- JudgementTracker.cs：谱面→判定闭环（自动漏判/按下命中/长条保持；Press* 已二分下界化→热路径 0 分配）；SetProfile 运行期档位热换（判定基准下拉=该 API）；Profile/JudgedDetail 事件；WindowStartMs 段界跳过（练习循环）。
- 练习/可视化：PracticeSession.cs（段循环/幽灵回放/Rate 0.5-1.5）+ JudgementLog.cs（滚动 200 判定均值/标准差/9 桶直方图/轨热图）。
- 改判定**必须**同时加 EngineChecks 断言（引擎源码\engine\Tests\EngineChecks\——确定性/零分配/热换/窗口乘数 ×1.0 防回归硬断言）。

### 4.3 渲染（IUiDraw 适配器约定）

- 宿主经 IUiDraw 绘制（DrawLine/DrawRect/FillRect/Text/MeasureText/PushClip…）；**Text 与 MeasureText 必须同口径**（emoji 估宽统一；D2D 用 TextLayout 真实 advance，GDI 用估宽——两侧已对齐）。
- UiCanvas：DesignW/H + SetViewport（虚拟坐标↔物理）+ RenderCaching（脏渲染）+ ToVirtual（letterbox 逆变换）；离屏取证（--shellshot）前 Invalidate 强制出图。
- 性能护栏（历史基线）：每帧零分配热路径（引擎壳 82.6B/帧）、字体/刷/笔静态缓存、UiElement 测量缓存有界（Render 虚拟化）、脏渲染默认开。

## 7. 附录：运行/调试速查与常见坑

- 启动：双击 输出产物\发布\Milestone.exe；或 输出产物\bin\Release\net8.0-windows\win-x64\Milestone.exe。
- 日志：exe 旁 Log\chartplayer-yyyyMMdd-HHmmss.log（Logger.LogDir=BaseDirectory\Log）；菜单「📋 打开日志」=打开该目录。
- 配置：%LOCALAPPDATA%\ChartPlayer\config.json（ChartsFolder 等；t62 已加一次性迁移标记 ChartsFolderMigrated）。
- 皮肤：Player\skin.json（程序目录）优先，其次 exe 目录 skin.json。
- 常见坑：
  1. 改了 UiText 但界面没变 → 编译产物没更新/用了旧 bin（确认 输出产物\bin 时间戳）。
  2. 文字截断/重叠 → 没走 UiMeasure/AutoShrinkFont/Ellipsis 三件套（参考 SectionHeader/PathLabel 实现）。
  3. emoji 压字 → UiGlyphRuns 测量≠推进（检查适配器是否同口径）。
  4. 新模式谱面不显示 → ModeInfo 键数/解析器/GamePanel 分派三处至少一处漏。
  5. parity 红 → 先看 基线 diff（parity-text-baseline.json），确定是有意改动再同步，禁止静默改基线。
  6. 打包后启动黑屏/找不到资源 → 内容根约定：发布件 = exe 旁 Chart\；皮肤 png 用 @2x 时注意命名。
