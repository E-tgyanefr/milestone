零基础更改指南：第一次动手改 Milestone

 

适用对象：从没写过代码的用户 · 手册版本：v1.0（t62 四目录迁移后）
你只需要：一台 Windows 电脑 + 记事本/VS Code + 本指南。五个任务按顺序做，每个都有 目标→文件→改哪行→验证→回滚。
不用怕改坏：每个任务都提供回滚步骤；重要文件先备份（复制一份到桌面备份文件夹）。

 

0. 开始之前（10 分钟准备）

 

0.1 你要认识的东西

 

名词通俗解释
源码用文字写成的程序文件（.cs 后缀），记事本能打开
构建（build）把源码变成可运行的程序（Milestone.exe）的过程
发布（publish）打包成一份单文件 exe，拷给谁都能跑
常量程序里固定的文字，写在 UiText.cs 这类文件里
谱面（.mil）一首歌的音符数据，JSON 文本格式，记事本能编辑
程序目录exe 所在文件夹；游戏内容（谱面/存档/日志）都放在 exe 旁边

 

0.2 工具检查

 

1. 打开 PowerShell（在任意文件夹地址栏输入 powershell 回车，或开始菜单搜 PowerShell）。

2. 输入 dotnet --version 回车——显示 v8.x 说明可构建；如果没有，先安装 .NET 8 SDK（微软官网下载 .NET SDK 8.0，装完重开 PowerShell）。

3. 确认项目在：输入 cd D:\Users\etgya\Desktop\milestone\游戏源码 回车（路径按实际调整）。

 

0.3 备份习惯（重要）

 

  • 改任何文件前：先把该文件复制一份到 D:\Users\etgya\Desktop\milestone\输出产物\dev\我的备份\（保留原始内容，回滚时复制回来）。
  • 改完构建成功再删备份。
  • 构建前先关掉正在运行的 Milestone 窗口（否则 exe 被占用构建会失败：错误提示“文件正由另一进程使用”——关掉游戏重跑命令即可）。

    任务 1：改主菜单按钮文字（最简单，先做这个）

     

    目标：把主菜单第一个按钮「▶ 开始游戏」改为「▶ 开始游玩」，并看到效果。

     

    文件路径：游戏源码\源码\CoreUtil\UiText.cs

     

    改哪行：找到第 25 行（搜索汉字 开始游戏 最快）：

     

    ~~~

    public const string MenuPlayGame = "▶ 开始游戏";

    ~~~

     

    改成：

     

    ~~~

    public const string MenuPlayGame = "▶ 开始游玩";

    ~~~

     

    验证：

     

    1. PowerShell（工作目录=游戏源码\）：dotnet build -c Release（看到 0 警告 0 错误）

    2. 运行：..\输出产物\bin\Release\net8.0-windows\win-x64\Milestone.exe

    3. 主菜单第一个按钮应显示「▶ 开始游玩」；点它进选歌正常。

     

    回滚：把 UiText.cs 该行改回 MenuPlayGame = "▶ 开始游戏"; 再构建。

     

    小知识：全部界面文字都集中在这一个文件（UiText.cs）。修改任何按钮/标题/提示文字都用同样方法——搜索那句话，改双引号里的内容。禁止跑到别处（界面代码）里直接写中文，否则下次想改就找不到了。

    任务 2：改主题色（给界面换个调子）

     

    目标：把界面里的“玻璃白”层调亮一点（或换强调色）。

     

    文件路径：引擎源码\engine\Ui\UiTheme.cs

     

    改哪行：文件里有主题令牌定义（颜色/间距/圆角/字号）。搜索 new RgbaColor( 找到默认初始化区块（约第 100-160 行），例如：

     

    ~~~

    Glass = new RgbaColor(255, 255, 255, 26); // 玻璃白：26=透明度（0~255，越大越不透明）

    ~~~

     

    把 26 改成 60（玻璃更亮更实）：

     

    ~~~

    Glass = new RgbaColor(255, 255, 255, 60);

    ~~~

     

    同样格式可改 Bg（根背景深空近黑）、Accent（强调色）、TextPrimary（主文字色）等——new RgbaColor(红, 绿, 蓝, 透明度)，每项 0~255。

     

    验证：

     

    1. dotnet build -c Release（工作目录=游戏源码\）

    2. 运行 ..\输出产物\bin\Release\net8.0-windows\win-x64\Milestone.exe

    3. 主菜单/卡片/按钮的玻璃质感应更亮。想快速看效果可用：..\输出产物\bin\Release\net8.0-windows\win-x64\Milestone.exe --shellshot D:\Users\etgya\Desktop\milestone\输出产物\dev\theme-test（生成三张页面截图）。

     

    回滚：把 RgbaColor 的透明度改回原值，重新构建。

     

    小知识：主题=颜色/字号/间距；想改音符位置、轨道宽度等几何→那是「布局编辑器」（设置→皮肤→在皮肤中编辑布局，或主菜单→布局编辑器），别有混淆。

    任务 3：加一个模式预设（让引擎认识一个新模式）

     

    目标：添加 5K Mania 预设「mania5」，并用引擎无头模式跑通它（引擎层面验证）。

     

    文件路径：引擎源码\engine\EnginePresets.cs

     

    改哪行：第 81-89 行是现有 mania4 预设块：

     

    ~~~

    Id = "mania4", Display = "Mania 4K", Field = RulesetFieldType.Lane, Keys = 4,

    （后续 1-2 行：示例谱种子/判定配置简介，依文件内实际结构整块复制）

    ~~~

     

    完整复制 mania4 整块（含它的属性行，约 81-89 行），粘贴在它下面，然后把第一行改成：

     

    ~~~

    Id = "mania5", Display = "Mania 5K", Field = RulesetFieldType.Lane, Keys = 5,

    ~~~

     

    注意：只改 Id 里的 mania5（全小写英文），Display 是给人看的名字。

     

    验证：

     

    1. PowerShell：cd ..\引擎源码\engine\EnginePlay（相对 游戏源码\）

    2. dotnet run -c Release -- --list（应看到 mania5 出现在预设表）

    3. dotnet run -c Release -- --preset mania5 --headless（输出 ACC 与无头播放结果=成功；报错就回滚）

     

    回滚：删掉粘贴的那整块（或从备份恢复 EnginePresets.cs）。

     

    小知识：预设=引擎的“玩法配方”（哪种场/几键/什么判定）。游戏内的 AI 演示等级表是另一份数据（游戏层），自建预设先保证引擎层闭环；要把新模式做成完整的可游玩法，看《工程说明.md》第 2 章 8 步链路。

    任务 4：打包并生成桌面快捷方式

     

    目标：把游戏打包成一份单文件 exe（发布件），并在桌面建快捷方式。

     

    文件路径：游戏源码\（构建）；输出产物\发布\（发布件）；桌面（快捷方式）。

     

    做法：

     

    1. PowerShell（工作目录=游戏源码\）：dotnet publish -c Release -r win-x64 -o ..\输出产物\发布\

    2. 等待完成（首次约 1-3 分钟）。打开 输出产物\发布\ 看是否有 Milestone.exe（单文件）与 skin.json。

    3. 双击 Milestone.exe——它旁边会自动出现 Chart\、Player\、PlayerData\、Log\ 等文件夹（游戏内容根=程序当前目录）。

    4. 建快捷方式（PowerShell 里执行）：

     

    ~~~

    $ws = New-Object -ComObject WScript.Shell

    $lnk = $ws.CreateShortcut("$env:USERPROFILE\Desktop\Milestone.lnk")

    $lnk.TargetPath = "D:\Users\etgya\Desktop\milestone\输出产物\发布\Milestone.exe"

    $lnk.WorkingDirectory = "D:\Users\etgya\Desktop\milestone\输出产物\发布"

    $lnk.Save()

    ~~~

     

    验证：桌面出现 Milestone 快捷方式，双击能启动游戏；游戏内日志（📋 打开日志）打开的文件夹=发布件 exe 旁的 Log。

     

    回滚：发布前先把 输出产物\发布\Milestone.exe 复制一份到备份文件夹；要回旧版就拷回来覆盖（同时删除新版本生成的 Chart\ 等运行目录或保留亦可）。

    任务 5：做一张 4K Mania 谱并玩到它

     

    目标：用现成示例谱改出一张自己的谱面并游玩。

     

    文件路径：输出产物\示例内容\Milestone示例\Mania 4K 示例.mil（源模板）；输出产物\发布\Chart\（发布件谱面目录）。

     

    做法：

     

    1. 复制「Mania 4K 示例.mil」到 输出产物\发布\Chart\ 并改名「我的第一张谱.mil」。

    2. 用记事本打开（右键→打开方式→记事本）。它是 JSON 文本：

     

    ~~~

    {

    "format": "milestone-1", // 格式标识（不要动）

    "mode": "mania", // 玩法

    "title": "Milestone 试玩 · Mania 4K", // 曲名（改成你的）

    "artist": "Milestone Team",

    "bpm": 120, // 速度

    "offset": 0,

    "audio": "", // 音频文件（留空=无声音）

    "keys": 4, // 键数

    "notes": [ // 音符数组

    { "t": 1000, "c": 0 }, // t=毫秒(第1000毫秒=1秒), c=轨道0~3

    { "t": 1500, "c": 1 }

    ]

    }

    ~~~

     

    3. 改三处：title 改成你喜欢的名字；bpm 120 改成 140；在 notes 数组里最后一行 } 后面加一行 { "t": 12000, "c": 0 },（12 秒处 0 轨一枚音符）。

    4. 保存（UTF-8 编码，记事本默认即是）。

    5. 双击 输出产物\发布\Milestone.exe 启动 → 主菜单选歌（默认目录=exe 旁 Chart\）→ 应看到「我的第一张谱」→ 点击游玩：DFJK 对应 1-4 轨。

     

    验证：选歌页出现新谱、能游玩、ESC 回主菜单正常。若想立刻看到效果但不想进游戏：Milestone.exe --shellshot <目录> 三页截图（选歌页为 songs 页）。

     

    回滚：删掉 发布\Chart\我的第一张谱.mil 即恢复。

     

    延伸：更多格式说明见 输出产物\示例内容\测试格式\（mania_test.osu / phigros_test.json / arcaea_test.aff / cytus_test.txt…每种格式一个最小样例）；段位谱面放 Chart\ 后主菜单「段位挑战」能扫到。

    6. 常遇到的问题（排查表）

     

    现象原因解决
    dotnet 不是内部或外部命令没装 .NET 8 SDK装 SDK；或重开 PowerShell
    构建报“文件正由另一进程使用”游戏还在运行关掉 Milestone 窗口再 build
    改完没变化用了旧版本 exe重新构建；确认跑的是 输出产物\bin\…\Milestone.exe
    中文乱码编辑器保存编码不对另存为 UTF-8 再试
    谱面选歌页看不到文件夹没放对放发布件 exe 旁 Chart\；或曲库管理页→选择文件夹 指向你的目录
    想恢复出厂删除 exe 旁 Player\ 与 config（%LOCALAPPDATA%\ChartPlayer\config.json）重新启动会重建默认
    parity 检查报“缺文案”改了作为基线键的文案这是正式回归工具；如果你只是自己玩，忽略即可（或按 工程说明.md 5.4 同步基线）

    附录 A：术语表（多举几个例子）

     

  • 源码/编译：源码=文字版程序（.cs），编译=把它变成 exe。构建命令 dotnet build 只做这一步；publish 额外打成单文件分发版。
  • 常量/字符串：UiText.cs 里 MenuPlayGame = "▶ 开始游戏" 中，引号内叫“字符串常量”，MenaPlayGame（首字母大写小驼峰）是它的名字。程序里写 UiText.MenuPlayGame 就代表那句话——所以你只改一处。
  • 命名空间/类：程序文件的组织方式；搜索功能（Ctrl+F）足以应付日常更改，不需要懂面向对象。
  • JSON：带花括号和引号的文本数据格式；谱面/配置都是它。改 JSON 时注意：每条数据后面要有逗号（最后一个没有），多/少逗号是新手最常犯的错——报错时先看逗号。
  • 程序目录（BaseDirectory）：exe 所在的文件夹。游戏所有内容（谱面 Chart\、存档 PlayerData\、皮肤 Player\、日志 Log\）都放这里；快捷方式的“起始位置”也要指向它。

    •  

    附录 B：谱面 JSON 常用字段速查（.mil）

     

  • format：固定 milestone-1（别改）。
  • mode：玩法（mania/phigros/arcaea/cytus/osustd/iidx/maimai/adofai/adofai2/loopcompose）。
  • title / artist / version / bpm / offset / audio：曲名/作者/难度版本/每分钟节拍数/音频偏移毫秒/音频文件名（放同目录，留空=静音）。
  • keys：键数（mania 4/6/7/8；iidx 8）。
  • notes：数组，元素=音符：
  • 普通音：{ "t": 1000, "c": 0 }（t=毫秒时间，c=轨道 0 起）。
  • 长条：{ "t": 4000, "c": 1, "e": 5000, "type": "hold" }（e=结束毫秒，type=hold 长条）。
  • 其他模式字段各异（Phigros 用事件数组、Arcaea 用 arc/def/sky 等）——以 输出产物\示例内容\测试格式\ 对应样例为准。
  • 多模式谱：顶层用 parts 数组（每部件一个 mode/notes），打开时选部件，游玩中 M 键切换。（样例：Milestone示例\多模式示例.mil）

    •  

    附录 C：找不到按钮文字？三步搜索法

     

    1. 在 游戏源码\源码\CoreUtil\UiText.cs 用 Ctrl+F 输入按钮上看到的字（如 开始游戏）。

    2. 若没有——搜全部源码（VS Code：Ctrl+Shift+F，文件夹=游戏源码），输入“游戏”之类关键片段；找到后优先把它挪进 UiText.cs再改（新文字进常量表，旧代码改引用）。

    3. 仍然没有：文字可能在代码里由格式拼出（如 MenuStatsFormat + 数字），改该常量模板即可。
