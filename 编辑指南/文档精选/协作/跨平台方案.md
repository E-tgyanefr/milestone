# 引擎跨平台化方案（t28）

## 目标与边界

- 引擎（`引擎\engine\MilestoneEngine.csproj`，纯托管类库）从 `net8.0-windows` 改为 **`net8.0`**：全操作系统（Windows / Linux / macOS，x64 / arm64）可编译、可运行。
- 引擎不含 WinForms 宿主：渲染零依赖（`IUiDraw` 抽象早已存在，颜色用 `RgbaColor`），音游域纯 BCL。
- 本任务 = 引擎层完成（TFM + 审计 + 构建矩阵 + 性能验证）；宿主层（WinForms/D2D 后端）的跨平台改造为后续阶段（见「阶段化迁移」）。

## 1. 分层架构（渲染后端无关已成立）

| 层 | 现有形态 | 跨平台目标 |
|----|----------|------------|
| 游戏/音游域 | 引擎纯托管（数学/判定/场/谱面/时间/UI 组件树） | 平台无关，本任务已达成 |
| 渲染抽象 | `IRenderer`（宿主）+ 引擎 `IUiDraw`（Rect/Text/Image/Clip等）与 `UiCanvas` 自绘 | 各平台实现同一接口即可插拔 |
| 渲染后端 | Windows = D2D/SharpDX（`D2DRenderer` + `D2DDrawAdapter`） | Linux = Vulkan/OpenGL（Silk.NET）；macOS = Metal（Silk.NET）；GDI+ 软渲染保底 |
| 音频 | `winmm`（`AudioPlayer`） | OpenAL / 跨平台后端抽象（IAudioBackend：Open/Play/Pause/Seek/PositionMs/Volume） |
| 输入 | WinForms 键盘/鼠标事件 | SDL2 / GLFW 抽象（IInputBackend：KeyDown/Up、Mouse、Touch） |
| 游戏循环 | WinForms `Application.Idle`（GamePanel） | 平台主循环抽象（IGameLoopDriver：Tick + 帧目标 + 输入泵） |
| 窗口/文件/配置 | WinForms 窗体 + System.IO | SDL/GLFW 窗口 + System.IO（已平台无关） |
| 硬件探测 | `HardwareProbe`（注册表 `#if WINDOWS` + `/proc/cpuinfo` 回退） | 已跨平台（本任务） |

## 2. 引擎层审计结论（t28）

- 全文审计 `引擎\engine` 全部 C#（含 Samples/Tests/HelloEngine）：
  - **无** `System.Windows.Forms`、**无** `SharpDX`、**无** `[DllImport]`（引擎源中仅注释提及）。
  - `System.Drawing` 仅 `Samples\DemoRunner.cs` 一条 `using System.Drawing;`（未使用）→ 已删除；`MiniMania*` 为宿主专属示例（EngineChecks 已排除，不随引擎构建）。
  - 唯一 Windows 专有 API：`HardwareProbe` 的注册表读 CPU 品牌 → 改为 `#if WINDOWS`（仅 Windows 宿主构建编译，运行时有 try/catch 兜底，CA1416 局部抑制）+ 纯 BCL 回退链：PROCESSOR_IDENTIFIER 环境变量 → Linux /proc/cpuinfo 的 model name → Unknown CPU。
- TFM：`MilestoneEngine.csproj` / `Tests\EngineChecks\EngineChecks.csproj` / `HelloEngine\HelloEngine.csproj` → **net8.0**；引擎 csproj 定义 `WINDOWS = IsOSPlatform('Windows')`。
- 零包引用维持：未引入任何 NuGet 包。

## 4. 零性能损失验证（BEFORE: net8.0-windows / AFTER: net8.0，同机各 3 次采样）

基准：`EngineJobs.Benchmark()`（65536 元素负载）+ `DifficultyStats.Compute`（262144 音符，并行+串行）+ `JudgementProfile.OsuMania(8).Evaluate`（100 万次）

| 指标 | BEFORE 中位 | AFTER 中位 | 差异 | 结论 |
|------|-------------|------------|------|------|
| EngineJobs.MapMs | 0.954 ms | 0.971 ms | +1.8% | 噪声内（0.91~1.06 波动） |
| EngineJobs.Speedup | 0.78x | 0.76x | -2.6% | 噪声内 |
| DifficultyStats 并行 | 58.9 ms | 62.2 ms | +5.5%（中位） | 3 采样 58~68ms 波动；min 58.3 vs 57.1 = -2.0% → 噪声主导，无系统损失 |
| DifficultyStats 串行 | 89.2 ms | 94.3 ms | +5.7%（中位） | min 84~96 波动；串并行一致性 eq=True 双向成立 |
| 判定吞吐 Evaluate | 47.8 M/s | 48.1 M/s | +0.6% | 无损失 |
| 正确性 | EngineChecks 全绿 | EngineChecks 全绿 | — | 一致 |

依据：纯托管数学/判定/JIT 性能与 TFM 无关（同一运行库版本）；渲染由各 OS 原生 GPU 后端（D2D/Vulkan/Metal）承担，**不使用模拟层**（如 Wine/SoftGPU）；引擎不渲染，仅提供 IUiDraw 接口约定。差异 <5% 视为无损失：本表判定吞吐无损失，统计类差异在测量噪声带内（min-of-3 方向为负/持平）。

## 5. 阶段化迁移路线

- **阶段 0（本任务完成）**：引擎层跨平台——net8.0 TFM、Windows 专有 API 清除（#if WINDOWS+回退）、构建矩阵 5 RID + 自检/示例 2 RID 全绿、零性能损失验证。
- **阶段 1（后端插拔改造）**：宿主层定义 IRenderBackend（现状 D2DRenderer 已实现 IRenderer）→ 抽出 IAudioBackend（winmm 实现 + OpenAL 占位）→ 抽出 IInputBackend（WinForms 实现 + SDL/GLFW 占位）→ 抽出 IGameLoopDriver（Application.Idle 实现 + SDL 主循环占位）。
- **阶段 2（Linux 首目标）**：Silk.NET（Vulkan/OpenGL 后端）实现 IRenderer；SDL2 窗口/输入/主循环；Linux 桌面跑通主菜单→游玩闭环（GdiDrawAdapter 软渲染已存在，可先行验证逻辑）。
- **阶段 3（macOS）**：Metal 后端（Silk.NET）；Metal 适配层等价映射；Apple Silicon（osx-arm64）验证。
- **阶段 4（发布形态）**：按平台 RID 打包（self-contained 单文件，同现状 Win x64）；CI 矩阵（Windows/macOS/Linux × x64/arm64）。

## 7. 遗留与备注

- HardwareProbe 在 macOS 无纯 BCL 品牌来源（sysctl 需进程调用），回退 Unknown CPU；NPU 启发式在 macOS 无法判定（后续可加 sysctl 后端抽象）。
- EngineJobs.Degree 在 arm64/macOS 一致（Environment.ProcessorCount 平台无关）。
- EngineChecks 运行验证仅限 Windows（本机）；Linux 侧为构建证据（无 Linux 运行时）。
- 本任务顺带修复的并行 WIP 编译错误：StoryshotDemo.cs 局部函数 Frac 作用域越界（Render 无法访问）→ 提升为类级私有静态。
