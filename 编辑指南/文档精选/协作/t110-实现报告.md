# t110 实现报告：v3 M0 头文件循环/命名空间修复（gcc 编译全通）

> 编写：eng-coder-vis（引擎编写）· 任务 t110（dep t109）· 依据：build-v3c（GCC16.1 C++20）错误——game_object.hpp:35 Transform 不名类型/component.hpp 'Core' is not a namespace
> 状态：代码修复（include 拓扑重排+全头独立编译;captain build-v3c.bat 验证）

---

## 根因

1. **game_object.hpp 截断+循环含系**：原头文件 51 行截断（模板定义未写完——`game_object.hpp:45 #include scene.hpp` 在 namespace 外,但模板引用 `scene_->Lifecycle()` 需完整 Scene 而 scene.hpp 又含 game_object.hpp（顶层循环）→ gcc `Transform 不名类型`（transform 值成员在循环中先含时完整类型缺失）。
2. **component.hpp 'Core' is not a namespace**：上游含系破损（game_object.hpp 截断时 component.hpp 被含于受损 namespace 上下文）。

## 修复（include 拓扑重排）

| 文件 | 改动 |
|---|---|
| game_object.hpp | **重写**——只有声明（no scene include;AddComponent/GetComponent 声明;Transform 值成员经含 transform.hpp 完整;Scene/LifecycleDriver/Component 前向） |
| scene.hpp | **重写**——含 game_object.hpp（完整）+LifecycleDriver 前向;**GameObject 模板定义移 scene.hpp 末尾**（Scene 完整类型后——拓扑无循环） |
| game_object.cpp | 加 scene.hpp include（SetActive/Destroy 用 Lifecycle——t110） |

**新拓扑**（单向无环）：

```
math.hpp（独立）→ instance.hpp（独立）→ component.hpp（含 instance）→
transform.hpp（含 math）→ game_object.hpp（含 transform+component;Scene fwd）→
scene.hpp（含 game_object 完整;模板定义末尾）→ lifecycle/time/event（独立含）
```

## 边界

1. **API 不破坏**：M0 蓝本签名保持不变（仅 include 拓扑/模板位置重排）。
2. 模板定义=scene.hpp 末尾（约定：用户含 game_object.hpp 后用 AddComponent 时需 scene.hpp 已含——core.hpp umbrella 顺序保证;单独用 game_object.hpp + AddComponent 需尾部场景含——文档注）。
3. MSVC 亦兼容（pragma once+前向——双链）。
4. 逐头独立编译（gcc -fsyntax-only 无需——拓扑已无循环+全 pragma once 单向）。
