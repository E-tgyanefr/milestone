## 根因与修复

**根因**：`#define TEST_CASE(name)` + `name##_fn()` 拼接——传入字符串字面量（中文描述）时 `##` 将字符串拼接为标识符（gcc error：user-defined string literal / 非法标识符）。

**修复**（tests/ms_test/ms_test.hpp）：

```cpp
#define TEST_CASE(txt) \
    static void test_fn_##__COUNTER__(); \
    static ::ms_test::Registrar test_reg_##__COUNTER__(txt, test_fn_##__COUNTER__); \
    static void test_fn_##__COUNTER__()
```

- `__COUNTER__`=编译单元内唯一递增 → 匿名唯一标识符（test_fn_N/test_reg_N）——**拼接不再涉字符串**。
- Registrar 接 txt（中文描述——`Case.description` 字段;RunAll 打印描述）。
- **调用处零改动**：`TEST_CASE("ECS Registry：…")`（7 处测试用例保持中文描述）。

## 边界

1. `__COUNTER__` MSVC/GCC/Clang 全支持——双链兼容。
2. 同编译单元多 TEST_CASE=C 计数递增唯一;跨编译单元=各自唯一（匿名无 ODR 冲突）。
3. 描述字符串=中文（UTF-8 源）——Registrar 存 const char* 生命周期=静态字面量安全。
