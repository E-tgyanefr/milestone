## 逐点实现（MainForm.cs）

1. **旧主菜单去除（默认路径）**：
   - ctor `BuildMainMenu()` → 仅 `CliLegacy`（CLI 截图）提前构建；默认/引擎模式不构建——启动不再闪现旧菜单；
   - ctor `ShowMainMenu()`（启动直调）→ 仅 `CliLegacy`；`--legacyui` 在参数解析完成后（`_legacyUi && !_engineUi && !CliLegacy`）显式显示；
   - 全部 `_mainMenu` 引用加可空防御（Controls.Add / ESC / overlay / HideOthers / HideAllMenus）；
   - 旧 F1 菜单栏（`_menu` ToolStrip）：默认/引擎模式 F1 不再唤起（`(_legacyUi || CliLegacy)` 才切换）；BuildMenu 保留仅供 legacyui。
2. **Act() 返回语义（集中重定向）**：`ShowMainMenu()` 顶部加引擎壳重定向——
   `!_legacyUi && !CliLegacy && _engineShell 存活 && !_redirectToEngine` → `ShowEngineShell()`（Reopen/新建）；
   防递归 `_redirectToEngine`（引擎壳打开失败回退旧菜单时不再二次重定向）。
   → Act(联机/AI 演示/布局编辑器/回环作曲/迷你 mania/引擎 UI 演示) 与全部 legacy 面板 GoHome/ESC/取消路径
   （ShowLibrary/Settings/Folder/Mp/Calib/Editor、StartLoopComposer 结束、ShowEngineUiDemoLegacy.FormClosed、
   AiDemoPickChart 取消、PickPart 取消等 18 处 ShowMainMenu 调用点）自动统一回引擎菜单。
3. **legacy 页面自身返回钩子**：
   - 迷你 mania（`MenuMiniMania` 动作）：`FormClosed → ShowMainMenu()`（→引擎菜单）；
   - 引擎 UI 演示关闭：原 `ShowMainMenu()` 经重定向→引擎菜单（无改动）；
   - 布局编辑器 ESC：MainForm ESC → ShowMainMenu → 重定向（无改动）；
   - 回环作曲结束：`ExitToMenu → UnhostContent → 引擎壳`（既有 t50 路径，无改动）；
   - 联机大厅（MpLobbyForm 内嵌 MpEmbedPanel，TopLevel=false 无独立关闭）——返回走 mp 面板 GoHome → 重定向（无改动）。
4. **主窗体不再显示为主菜单**：默认模式 `_mainMenu` 不构建不显示；引擎壳关闭=退出应用（既有）；可见窗口数=1 保持。
5. **回归**：
   - parity legacy 快照（`MainForm.CliLegacy=true`）：E1/E6 保 CliLegacy 提前构建+显示旧菜单，文案快照/桥接校验口径不变；
   - stress/CLI 截图（--multishot 等 CliLegacy）不受影响；引擎模式相关 stress 无旧菜单依赖；
   - 主题切换 `RebuildMainMenu`（RebuildView null 安全）与 `ShowMainMenu(false)` 重定向兼容。
