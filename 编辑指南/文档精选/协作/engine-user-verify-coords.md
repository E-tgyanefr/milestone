## 建议给 coder-vis 的默认布局微调（同一批修复）
1. 主菜单 Logo：分段偏移常量 6px；如果以"整串测量宽"分段再按"分串绘制"→ 改为分串测量或硬编码段位。
2. osustd HUD：Score 锚点 (0.020W, 0.035H) → 下移至 (0.020W, 0.075H)；或顶部徽章行下移 8px。
3. Cytus/IIDX（及 Phigros 等无轨）：judge 文字默认位从 (0.5, HitLineY±) 计算改为跟随判定线并让出左侧 HUD 带（x≥160 或 y 偏移 +40）。
4. maimai：特殊音符/未映射方位 note 的默认渲染点=环心 → 修正为最近方位或程序断言；非修不可。
5. Arcaea：判定文字绘制象限=quad 上层（当前被四边形盖住）；默认场景 scale 与 note 尺寸复核。

## 与 §5.5 的符合性结论
- 符合：无（本轮验证项全部命中问题）。
- 不符合：Logo 段间距 32px≠6px；osustd 徽章×Score 重叠；IIDX 判定字×HUD 重叠；Arcaea 判定字被四边形遮挡。
- 待复核：右上按钮图标槽宽——补充测量：顶条白色文字总跨度 x=934..1258（y=56..76），按钮底色未检出独立色块（按钮底与背景色差低于阈值），按钮真实边界/图标槽宽需 coder-vis 用控件矩形直接取值（或放大 2x 截图再测）。
