# t74 修复报告：--foldershot B16 崩溃（CaptureCanvasFrame 尺寸保护）

> 归属：coder-vis。依据：verify-t71/foldershot.log（07:51:27 实测）。工程：游戏源码/Milestone.csproj（四目录迁移后路径）。

## 根因
`EngineMainShell.CaptureCanvasFrame(UiCanvas c, ref Bitmap bmp)` 使用字段 `_ltx/_lty/_lscale`（OnPaint 每帧 letterbox 计算）做 `TranslateTransform/ScaleTransform`。
- `--foldershot` 为**离屏取证**路径：`RunFolderShot → GoToPage("folder") → GoTo → 转场 -> CaptureCanvasFrame`，窗口从未显示 → **OnPaint 从未执行** → `_lscale` 保持字段缺省 **0** → `g.ScaleTransform(0f, 0f)` → `System.ArgumentException: Parameter is not valid`（Graphics.ScaleTransform 不允许 0/负数/NaN/Inf）。
- 栈：ScaleTransform → EngineMainShell.CaptureCanvasFrame → GoTo → GoToPage → RunFolderShot。

## 修复（尺寸保护，B16）
`游戏源码/源码/Play/EngineUi/EngineMainShell.cs` CaptureCanvasFrame：
- 目标位图尺寸钳制 `w<1→1280 / h<1→800`；
- letterbox 改按**目标位图自身**求取：`scale = Min(w/1280, h/800)`，并加 `scale<=0 / NaN / Infinity → 1.0` 三重保护；`tx/ty = (d - 1280/800×scale)/2`；
- 用局部 `tx/ty/scale` 替换陈旧字段 `_ltx/_lty/_lscale` —— 离屏/头less 路径不再依赖 OnPaint 先例（转场缓存路径同函数同保护）。
