## 4. 已知边界/标注

1. **转场简化**：批2 页面切换=立即切换（构建新页 canvas）；SceneTransition/SceneManager 转场 API 齐备（DemoRunner 覆盖），真正的 Slide/Fade 转场帧合成留批2 跟随项。

3. **ToolApp 引擎自检卡**：主页「引擎自检」=提示语（真实自检入口=EngineChecks/MilestoneEngine --check，工具窗内嵌自检页可批5 评估）。
4. **DrawStatus 纯图形无文字**：命中率色条+完成色带（设计 C1 状态可视化方案）。
5. **PreviewController.RunAuto 语义**：与 Ruleset.RunAuto 同口径（到达时刻 press + PressRing/PressField 家族分支），10 预设全命中 acc=1.000 实测一致。
