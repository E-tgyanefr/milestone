## 边界/说明

1. 验收：MilestoneEngineEditor.exe 启动=六区窗口可交互（E1-3 面板核心）+Play/Stop 运行当前场景（ED4 快照隔离）+--editor exit 0——代码层+断言齐；窗口级视觉=试玩目视（E1-3 已断言面板/API 层）。
2. SaveScene=SceneAsset JSON 草稿（阶段 C SceneSerializer 正式接 AssetManager）；Ctrl+S 零依赖 P/Invoke（GetKeyState）。
3. Play=快照隔离（ED4 v1 语义=运行副本弃用 Stop 回滚——P2 现场修改回写）；Pause=停摆/继续。
4. 独立 exe 发布=captain publish 单文件（csproj target 已在）；MilestoneEngineEditor.exe 无参默认 --editor（exe 名检测）。
