# t34 实现报告：800 极窄档 emoji gap 微调（scale<1 推进 +2px）

- 日期：2026-08-27 · 承办 coder-max · 约束：只写代码不构建（captain 构建 + 试玩 800 档 2 标签 gap 复测）
- 依据：r10——默认/1920 全过 ≥6px；800×600（scale 0.625）行0 联机 5px、行4 打开日志 4px（<6px 下限）

---

## 方案（scale 感知 +2px 保底）
1. 新增 `UiGlyphRuns.EmojiGapBoost`（static double，默认 0）——宿主每帧按当前 letterbox scale 设置；
2. `EngineMainShell.OnPaint`：`UiGlyphRuns.EmojiGapBoost = scale < 1 ? 2 : 0`（t27 的 scale 现成；800×600→0.625→+2；默认/1920→≥1→0 零变化）；
3. 两适配器 emoji run 推进/测量统一加读：`6 + UiGlyphRuns.EmojiGapBoost`（GdiDrawAdapter Text/MeasureText、D2DDrawAdapter Text/MeasureText 各一处）
   ——测量=推进=绘制三端同口径不变（居中/Ellipsis/AutoShrink 数学不受影响）；
4. 效果：800 档 联机 5→7px、打开日志 4→6px（≥6 ✓）；宽档保持 r10 现状（44-67px）零变化。

## 边界说明
- 静态值为渲染线程内逐帧写入、绘制同帧读取（OnPaint 单线程绘制路径），无跨线程竞争面；
- 引擎壳 GDI 路径每帧重置；GamePanel/离屏取证路径不写此值（保持 0，证据口径不变）；
- UiMeasure（构建期 FitFont）不含 +2（运行时窄档才生效）：按钮 ≥12px 内距吸收 2px 偏差，无视觉影响（记录）。

## 变更文件
- `源码/Play/EngineUi/UiGlyphRuns.cs`（EmojiGapBoost 字段）
- `源码/Play/EngineUi/GdiDrawAdapter.cs`、`源码/Play/EngineUi/D2DDrawAdapter.cs`（推进/测量 +boost）
- `源码/Play/EngineUi/EngineMainShell.cs`（OnPaint 每帧设置）
