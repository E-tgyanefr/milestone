# UI 留白体系设计规范（艺术性留白）

> 原则：留白优于装饰。负空间是设计的呼吸——用大边距、低密度、强层级代替密集布局。

## 1. 留白率目标（背景/非元素像素占比）
- 主菜单页 ≥ 60%；选歌页 ≥ 55%；设置页 ≥ 55%。

## 2. 8pt 节奏间距（S 尺）
- S0=0 · S1=8 · S2=16 · S3=24 · S4=40 · S5=64 · S6=96 · S7=128
- 页面四边安全边距 ≥ 64；内容最大宽 900（1280 画布 → 两侧各 190 留白）；纵向大分区 ≥ 48。

## 3. 12 列网格（内容 900 宽 = 12×75）
- 内容居中留白带；栏位跨越 4/6/12 列；卡片 3 列（每 284 宽 + 32 间距）。

## 4. 字体层级与留白节奏
- FnDisplay 44（Logo）/ FnH1 30（页标题）/ FnH2 22（按钮）/ FnTitle 16 / FnBody 13 / FnCaption 11
- 标题与正文间距 ≥ 24；块间 ≥ 40；标题上下留白 = 1.5× 字高（呼吸感）。

## 5. 色彩氛围
- 基调：深空渐变（#0D1424→#04060C）· 低饱和玻璃卡 #1C2740（透明度 0.92）· 唯一强调 #2D6CFF · 次要文字 #7F93BB
- 视线降噪：次要元素透明度 0.5（徽章/统计/提示）；星点 alpha ≤ 60 且避让内容中线。

## 6. 艺术性构图（每页）
- Logo 区：上留白 96 + 下留白 48；双色 Logo + 64px 细线（强调色 1px）+ 标语弱化 11pt。
- 主操作区：唯一主按钮（高 56）+ 4 支柱按钮（2×2，高 48）；其余功能收敛为「更多」紧凑区（2 列 × 7 行，高 36，低饱和）。
- 呼吸分区：页头 / 主区 / 更多 / 页脚 四段，段间距 48~64；页脚（徽章弱化行 + 提示）小字号居中。
- 选歌/设置页：页头（标题 + 返回，上留白 80）→ 主体（上留白 48）→ 页脚留白 80。

## 7. 参考
- Apple.com：超大边距 + 单列叙事留白；Linear：65% 负空间 + 精致强调色；Stripe：浅渐变 + 大间距层级。

## 8. 执行要点
- 全部 UiText 文案逐字不变；交互（点击/悬停/转场）不变；仅布局/间距/透明度/字体层级变化。
