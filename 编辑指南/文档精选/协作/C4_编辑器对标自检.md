# C4 编辑器对标自检报告(游戏内容 AI · 2026-08-21)

> 依据《策划\需求.md》C4 与《主代理方向指导.md》§2.3。对照社区编辑器范式逐玩法自检 ChartEditorPanel.cs(5534 行),补齐明显缺失交互。子代理精读报告 + 主代理实施。

## 1. 架构总览

编辑器采用"**有轨/无轨二分**"(`ModeSystem.Tracked` 派生):有轨(mania/iidx/taiko/adofai/arcaea)→ `DrawTracked` 垂直轨道下落;无轨(phigros/cytus/osu!std/catch/maimai)→ `DrawTracklessField` 自由场。Arcaea 独享 3D 透视视图 `DrawArcaea3D`。交互:OnMouseDown/Move/Wheel/KeyDown 四入口 + `DragKind` 拖拽状态机(24 种)。已有:撤销栈(100 层)、吸附(1/64~1/1)、部件(多模式同谱面)、事件编辑、多判定线、arc 3D 控制点、osu 四曲线滑条。

## 3. 本轮已实施(全部构建 0 错误)

1. **谱面属性编辑弹窗**(TOP1):工具栏 "✏️ 属性" → `ShowChartProperties()`(标题/艺术家/版本/段位名),`BuildChart` 自动生效。
2. **Ctrl+C/V 复制粘贴**(TOP2):`ClipboardNote` + `CloneNotes(Note)` 深拷贝 + `PasteNote()`(PushUndo+去重+选中),以播放头为基准偏移粘贴。
3. **Mania 密度柱状图**(TOP3,策划点名):`DrawTracked` 轨道右侧窄条,每小节每列音符计数(1=蓝/2+=橙/4+=红,高度按峰值归一)。
4. **有轨拖拽改列**(TOP4):`OnMouseMove` case1 加横向改列(长条 EndCol 联动),补齐 Malody NoteArt 招牌交互。
5. **Catch 编辑器断点修复**(TOP5):`DrawFieldBackground`/`FieldNotePos`/`DrawFieldNote`/`TracklessFieldAt`/`ApplyTracklessField` 补 Catch 分支——横盘+8 列格+下沿判定线+水果圆+hold 竖条+列量化放置。
6. **重做 Ctrl+Y**(2026-08-21 追加):`_redoStack` 对称实现——Undo 压入 redo、Redo 反向恢复、PushUndo/NewChart/载入清 redo;`RedoRequest` + OnKeyDown Ctrl+Y。
7. **Arcaea 选中 arc 切换虚实**(2026-08-21 追加):选中 arc 后 V 键切换 Decor(PushUndo);渲染按 Decor 降透明度(虚弧 0.45×,实机 void arc 更淡)。
8. **osu 空间网格吸附**(2026-08-21 追加):`TracklessFieldAt` osu 分支在网格开启时吸附到 16 格(与渲染网格一致,lazer PositionSnapGrid 语义)。
9. **osu 滑条 Repeats UI**(2026-08-21 追加):选中滑条后 +/− 键调整往返次数(下限 1,PushUndo;渲染已有 ↺×N 与往返动画)。
10. **多选**(2026-08-21 追加):Shift+点击加入/移出多选集(`ToggleMultiSelect`/`_selNotes`);Delete 批量删除(`DeleteSelected`)、方向键批量移动(`NudgeSelectedMulti`)。

## 3c. E-2 ADOFAI 俯视路径编辑器(策划清单,2026-08-21 首期)

策划定稿 E-2 为最高优先(范式错位)。首期已实现:
- **俯视棋盘路径主视图**(`DrawAdofaiTopdown`):路径在画布大区域按累计角度铺开——双轨菱形 tile(火轨暖/冰轨冷)、双轨路径线、末尾虚线追加提示,替代角落小轮盘预览
- **交互**:点击 tile 选中(角度框同步);点击路径末端=追加新 tile(时间=末音符+1 拍,角度延续当前累计角);Routlock 保留原轮盘预览
- 后续:点选 tile 改角度交互增强、拖 tile 改角度、Surgery(插入/删除段)、速度/旋转/Twirl 绑 tile 数值面板
