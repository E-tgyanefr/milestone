## 四、偏离/决策记录（评审需知）
1. **Save 返回值**：设计签名为 bool——实现为 AssetResult（14 错误码——验收 #3 需要「错误码+日志」；bool 不足以表达）。
2. **rot 存储=四元数 [w,x,y,z]**（示例为欧拉角 [x,y,z] 度数）：四元数忠实往返（欧拉→四元→欧拉存在歧义）；Test 断言按四元数。
3. **组件工厂并入 Register<T>**：if constexpr is_base_of<Component> → create —— 反序列化按类型名实例化组件（设计未明示——默认实现）。
4. **MILESTONE_REFLECT 需 ≥1 字段**（0 字段组件=编译错误——字段计数宏限制；文档化）。
5. **场景对象名=唯一约定**（父引用按名称——重复名=DuplicateName 错误码），与设计「名称唯一约定/环检测」一致。
6. **Prefab 实例化=模板 JSON 重解析**（PrefabAsset.json 载荷→ApplyObjectEntry）——避免 Component::Clone（M3 编辑器期评估完整挂接）。
7. **二进制骨架**：SaveBinary/LoadBinary 入口=NotSupported/ nullptr（M2-a 诚实声明——P1 同 schema 补全）。
