# 还原度闭环第二轮复核:Arcaea 截图机制修正后对比(2026-08-22)

## 重要修正

**此前 Arcaea 对比(0.572-0.607)使用的截图是菜单/黑屏**——旧 ScreenCapture 用 CopyFromScreen(仅前台可截),且短谱在截图前已结束游玩。
**改用 PrintWindow(PW_RENDERFULLCONTENT)+ 长谱后复核:**

| 指标 | 旧(菜单/黑屏截图) | 新(真实游玩截图) |
|---|---|---|
| 平均相似度 | 0.698 | **0.773** |
| 最高 | 0.828 | 0.829 |
| 最低 | 0.572 | 0.607 |
| 新截图匹配帧 | 0/47 | **44/47** |

**结论:Arcaea 画面还原度实际很高**(与实机相似 0.77+),此前低分是截图机制误报。
