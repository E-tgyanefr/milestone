## 四人分工
| 角色 | 谁 | 职责 |
|---|---|---|
| 决策者 | 当前代理（主代理） | 排优先级、定规格、验收、最终裁决；**唯一可执行文件操作者**（集成胶水/验证） |
| 程序员 | 本地 AI（qwen3-coder-30b，Ollama :11434） | 按规格编写原子件/引擎优化代码；只输出代码块；ASCII 字符串 |
| 策划 | 子代理（独立上下文） | 未来方向与"实机一致化"的对标参照物/验收判据（决策者决定是否执行） |
| 试玩 | 子代理（独立上下文） | 找游戏问题：代码级定位 + 证据（体检/自检/报告/代码路径） |

## 循环（每轮）
1. 试玩/策划子代理产出 → 决策者审并决策（执行/搁置/修改）
2. 决策者写规格 → 本地 AI 写代码 → 决策者集成 + 编译验证（0 警告 0 错误 + --selfcheck 0 等对应测试）
3. 决策者记录（任务板/消息板：谁写的、验证结果）→ 下一轮
