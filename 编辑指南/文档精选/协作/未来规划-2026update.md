## 0. 一句话主线

**本地数据 + 本地模型 = 玩家自己的教练与裁判；再把创作流水线串起来，让"谱面生态"自己长出来。** 本轮新增：**精简存量（R1）+ 创新玩法原型（R2）**，让代码库更可维护、并拥有一个区别于全部 9 玩法的自有玩法。

## 1. 现状底座（2026-08 盘点）

- 9 可玩玩法（Mania / maimai / Phigros / Arcaea / Cytus / osu!standard / Routlock / ADOFAI / IIDX），实机对比闭环达标（0.70+ 相似度基线）

- AI 侧：陪玩（70+ 等级）/ 段位训练（AI 调参过段）/ 教练文案（本地 LLM，P1-1 v1）/ 难度评估器（P1-2 v1，段位全序一致）
- 创作侧：编辑器体检（P2-1a ✅）/ 自然语言→事件（P2-1b ✅）
- 玩法侧：段位试炼循环 + AI 联机对手（P2-2 ✅）；回放 / 联机 / 144Hz 性能优化 / 人类模拟 / 引擎自检（selfcheck/modetest/edsim 34）

## 3. 实施顺序建议（滚动）

1. 第一步（本轮）：**R1 精简（进行中）→ R2 创新原型（M1 可玩 MVP）→ R3 文档刷新（并行）**
2. 第二步（1-2 周）：P1-1v2（复盘渲染，纯 UI+图）、P3-3 判定实验室（数据现成）
3. 第三步（2-4 周）：P2-3 一键入库 + P1-2v2 星级消费入口（互相反哺）
4. 远期（用户拍板）：P3-1 混合玩法、P3-2 演出层、R4 模板典库、P2-1c 语法扩展

## 4. 风险与边界（沿用提案 §3，仍有效）

- **本地模型能力有限**：LLM 只用于开放式短文本生成（复盘文案），不得用于结构校验/清单/长代码；必须可静默降级
- **性能红线**：新增模块不进游玩热路径；数据统计局后/空闲；维护 144Hz / GPU 满载线（FrameTargetMs 6.94ms 现状）
- **"与实机一致"是既成契约**：新玩法/演出一律走可选实验（R2/P3-1 默认实验性），不碰 9 玩法默认表现
- **版权**：难度评级/复盘不引入第三方内容；官方谱禁发布（自制谱渠道已建）
- **验证纪律**：任何改动交付 = 构建 0 警告 0 错误 + selfcheck/modetest exit0 + edsim 34/34 + 证据（edshot/shotdemo/人类试玩）
