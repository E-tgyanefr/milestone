## 四、偏离/决策记录（评审需知）
1. **ms_id=int64_t**（设计 long——Windows long=32 会截断 uint64 InstanceId；C# long 匹配）。
2. **ABI 增补 2 函数**：ms_assets_set_root（C# 侧 Save/Load 前置——设计无 SetProjectRoot 绑定；否则验收 #7 C# 侧不可行）+ ms_assets_save（二进制安全带长度——save_text 的 strlen 对二进制（bmp）无效；save_text 保留为文本便捷）。
3. **ms_component_spec.scriptType 语义=注册键**（可含实例后缀）：C# 侧 per-instance 键 FullName#n——规避 design「scriptType→spec 单键覆盖」多实例 userData 串扰（文档与设计意图一致实现）。
4. **引擎双渲染面**（parity 固定 1280x800 + 窗口客户区面）：保持跨语言 parity 哈希稳定且窗口呈现正确（设计未明示窗口 resize 与 parity 面的关系）。
5. **ms_engine_render(ctx)**：ctx 预留（C# OnRender 完全委托=P1）；当前渲染=内置演示场景（parity 源）。
6. **属性 ABI 面向原生（反射注册）组件**：C# 脚本组件字段=托管侧（M3 Inspector 时 C# 反射桥增补）；C# 包装 PropertyGet/Set/FieldsJson 已暴露（错误路径可验）。
7. **C# wrapper run 前提**：原生 DLL 目录（build/src/bind）+ mingw PATH（libstdc++ 等）——README 注。
