# 音符设计 - 全模式（NoteStyle 数据层 + 视觉设计卡）

> 起草：aihelper（本地 AI & 加速器 glue helper）· 2026-08-25
> 配套数据层：引擎/engine/NoteStyle.cs（NoteStyle{ModeKey, NoteColor, AccentColor, GlowColor, OutlineWidth, Approach, HitFx, Shape} + NoteStyleBook 每模式默认样式 + ToJson/FromJson 往返）
> 调研方式：web_search 检索真实游戏资料（参考 URL 见每张卡"参考来源"与文末清单，均为真实游戏 wiki/官方皮肤指南/教程页）
> 约束：引擎零依赖（颜色用 RgbaColor，不引 System.Drawing）；本文只做设计，不改渲染代码。

## 0. 设计统一原则

1. **可读性优先**：主色必须与背景对比足够；所有模式默认 "暗背景 + 亮音符"（与主流实机一致）。
2. **三色分工**：NoteColor=本体；AccentColor=长条/滑动体/次类型；GlowColor=接近圈/光晕。
3. **接近动画形态**（ApproachType）：
   - Fall=下落/接近线移动（键式模式默认）
   - Shrink=目标外圈收缩（osu 家族/Arcaea arc）
   - Sweep=扫掠/扫描线经过（Cytus/maimai）
   - Spread=从目标点扩散聚拢（ADOFAI tile/环形出场）
4. **打击特效**（HitFxType）：Burst=粒子爆发（脆感）/ Ring=扩散环（余韵）/ Star=星芒（高亮感）。
5. **形状语义**：Capsule=键式胶囊按住段；Bar=细长条（arc/激光/转盘）；Circle=圆点（触摸/打击类）；Diamond=菱形（扇形/方向）；Ring=环（环形场）；Tile=方块（网格/路径）。
6. **判定反馈**（各卡末行）：判定瞬间的通用表现 = 打击特效（HitFx）+ 判定文字（沿用 JudgeSettings 等级名彩色）+ 连击数字脉冲（Tween 缩放）；此层与 NoteStyle 解耦（渲染接入时消费三种色 + Approach + HitFx）。

## 12. NoteStyle 数据层接入约定（渲染接入时）

- 消费点：GamePanel/EditorCanvas 音符绘制处读取 \`NoteStyleBook.Get(ModeSystem.ModeId(mode))\`（ModeId 与 Schema 完全对齐：mania/phigros/arcaea/…/loopcompose）。
- Shape→绘制分派：Capsule/Bar/Circle/Diamond/Ring/Tile 各一个绘制函数，颜色三通道（Note/Accent/Glow）+ OutlineWidth 描边。
- Approach→动画：Fall=时间→位置；Shrink=外圈半径；Sweep=扫掠相位；Spread=弹出/聚拢占位。
- HitFx→打击特效：Burst=粒子发射器爆发（ParticleEmitter.BurstCount 配置）、Ring=扩散环、Star=星芒（新绘制分支，后续任务）。
- 序列化：\`NoteStyleBook.ToJson()\` 可落盘（玩家皮肤/主题覆盖用 \`FromJson\` 合并），引擎零依赖（仅 System.Text/StringBuilder）。
