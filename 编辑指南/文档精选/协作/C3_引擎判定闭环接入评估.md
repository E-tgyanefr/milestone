# C3 引擎判定闭环接入游玩端评估(游戏内容 AI · 2026-08-21)

> 依据《策划\需求.md》C3:评估 osu!std 滑条 tick/完整度结算、长条分段判定切换到引擎模型;给出结论(接入或记录差距)。本评估只读代码 + 写文档 + 最小接入,不启动游戏进程。

## 1. 现状盘点

### 1.1 引擎侧(引擎 AI 已完成,全部就绪)
- `RhythmCore.SliderNote`:ControlPoints(贝塞尔路径)/ TickCount / TickIntervalMs / TickTimes()(含头尾)/ HitTick(now, window)窗口内命中最近未命中 tick / Completeness(0..1)/ HeadTickHit / TailTickHit / ResetTicks。
- `JudgementTracker`:Judge / PressLane / PressRing / PressField / HoldLane,Board 内嵌。
- `ScoreBoard.ApplyTick(tier)`:tick 计分(不占连击/ACC,单独 TickScore 累计);`ApplyHoldTail(tier)`:长条尾段分数与权重 ×0.5(引擎指令4 已实现并有断言)。

### 1.2 主项目侧现状
- osu!std 滑条在 `PrepareModeNotes` 被重分类为 `Type="hold"`(头判定走 `Hit` → `_eng.Judge`,尾走 `OsuRelease`/自动完成 `HoldComplete`),转盘为 `Type="spinner"`。
- **中间 tick 不计分**:滑条只有头(300)+ 尾(300),无逐 tick 计分;完整度未进入结算。
- 松手:距尾 ≤100ms 视为完整(`HoldComplete`),否则 `HoldBreak`(MISS,断连)。
- `ParseOsu` 未解析 `[General] SliderTickRate`;Chart 模型无 tick 字段。
- 主项目结算:自持 `_score/_acc/_combo/_hits`,未直接使用引擎 ScoreBoard(判定经 `_eng.Judge` 引擎通道,统计在主项目侧)。

## 2. 接入决策

**结论:采用"轻量接入"——主项目复用引擎 tick 时间模型与规则语义,计分留在主项目结算通道(不整体切换 ScoreBoard,避免 9 玩法结算口径回归)。**

理由:
1. 主项目 `Note` 是轻量模型(无 tick 字段),整体切换 SliderNote 需重写滑条渲染/输入/回放/AI 四套路径,回归风险大;
2. osu!std 的 tick 判定语义简单(按住期间自动吃 tick、头必中、尾 tick 完整度),主项目滑条已按 hold 判定,只需在按住期间按引擎 tick 规则计分;
3. 引擎 SliderNote.TickTimes/HitTick 是纯计算,可直接移植同一公式(每 tick 分=30、完整度计入结算)到主项目,保证与引擎 DemoRunner 口径一致。

## 3. 接入设计(最小实现)

1. **Chart 模型**:加 `public double SliderTickRate = 1;`(osu 谱 `[General] SliderTickRate`,默认 1)。
2. **ParseOsu**:解析 `[General]` 段的 `SliderTickRate` 写入 `chart.SliderTickRate`。
3. **GamePanel**:
   - `OsuSliderTicks(n)` 惰性计算 tick 时间表:间隔 = 一拍时长 / SliderTickRate(拍时长 = 60000/Bpm;变速谱按事件近似取头段 BPM),列表含头尾。
   - `OsuSliderStep(now)`(并入现有每帧 Step):对每个按住中的 osu 滑条,用引擎同一窗口语义(主项目取 `JudgeSettings.Levels[0].Window` 作为 tick 窗口)命中到期 tick:
     - tick 命中:`_score += 30`(osu 基础分,无 combo 加成)、`_hits["tick"]++`、连击+1(osu 规则 tick 计入 combo)、`_burst`/音效可省;
     - 头 tick 由 `Hit` 已覆盖(不重复计);
     - 尾 tick 随完整度:完整度 <1 时松手仍 `HoldComplete` 但尾段分数按完整度折减(`_score += 300 × Completeness × 0.5`,对齐引擎 ApplyHoldTail 语义);完整度=1 全分。
   - 结算面板:`_hits["tick"]` 显示"滑条 tick x/y"(可选)。
4. **验证**:构建 0 错误;humantest 回归(mania 94.44% 等)不劣化;引擎 DemoRunner 已有 tick 断言(引擎侧),主项目侧加 osu 滑条谱 humantest 观察 tick 计数(待可弹窗时执行,本轮仅构建)。
