# t45 实现报告：ExitToLibrary 引擎模式回引擎壳修复

- 日期：2026-08-27 · 承办 coder-max · 约束：只写代码不构建
- 依据：试玩 P1 截图——AI 演示 ESC/结算 Back 跳 legacy 选歌页且主窗句柄丢失

---

## 根因
- `MainForm._game.ExitToLibrary`（AI 演示 ESC / 结算 Back）非 `_testPlayReturn` 分支直接 `ShowLibrary()`——
  引擎模式下 MainForm 隐藏（壳为唯一可见窗），直接 ShowLibrary 会以隐藏主窗显示 legacy 选歌面板，
  主窗句柄/可见性不一致（与 `ExitToMenu` 的引擎分支缺失同款）。

## 修复（照抄 ExitToMenu 同口径）
```csharp
// 非 _testPlayReturn 分支：
if (!_legacyUi)
{
    if (_engineShell != null && !_engineShell.IsDisposed) _engineShell.UnhostContent();   // 回到引擎窗 UI（壳自行显示）
    else ShowEngineShell();
}
else ShowLibrary();
```
- 引擎模式：UnhostContent 后引擎壳显示当前页（退出游玩回引擎 UI，与 ExitToMenu 完全同款）；
- 壳未建（异常/早期）：ShowEngineShell() 建壳；
- `--legacyui`：保持 ShowLibrary() 原语义。
