# t47 实现报告：ExitToLibrary 窗口显隐收口（壳 Show + 主窗体 Hide）

- 日期：2026-08-27 · 承办 coder-max · 约束：只写代码不构建（captain 构建 + 试玩复测）
- 依据：t44 复测（bin 21:45:45）——AI 演示 ESC 后主窗句柄=0 仍现

---

## 根因
- AI 演示经引擎菜单 Act 进入（`Act`：壳 Hide + 主窗体 Show 承载 GamePanel）→ ESC → ExitToLibrary；
- t45 修复只做了 `UnhostContent()`（解除承载），未显示壳、未隐藏主窗体——壳仍 Hidden、
  主窗体裸露空 GamePanel（窗口枚举口径=句柄异常）。

## 修复（MainForm.cs 两处，同口径收口）

### ExitToLibrary 引擎分支（t47 主修）
```csharp
if (!_legacyUi)
{
    if (_engineShell != null && !_engineShell.IsDisposed)
    {
        _engineShell.UnhostContent();
        this.Hide();                              // t47：主窗体让位（单窗口=引擎窗）
        if (!_engineShell.Visible) _engineShell.Show();
    }
    else ShowEngineShell();
}
else ShowLibrary();   // legacyui/CliLegacy 语义保持
```

### ExitToMenu 引擎分支（同源隐患一并收口）
- 回环作曲/布局编辑器等 legacy 入口（Act 同路径）游玩退出时同样存在壳 Hidden + 主窗体裸露——
  同步补 `this.Hide(); if (!_engineShell.Visible) _engineShell.Show();`（壳已可见时 Show 为无操作，零回归）。

## 变更文件
- `源码/Forms/MainForm.cs`（ExitToLibrary 引擎分支 + ExitToMenu 引擎分支，各局部一处）

2. 回环作曲/布局编辑器退出：同口径回引擎窗；
