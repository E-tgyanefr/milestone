## P0-1 设置·评级分区「评级按 ACC 固定档位」压叠

### 根因（代码级实锤）
- 引擎页评级分区仅一行：`RowInfo(UiText.SettingsGradeInfo)`，该常量含 `\r\n` 三段多行文本。
- Row() 把全文放进单行标签框（1 列标签宽 350、高 24、AutoShrinkFont 开、无 Ellipsis）。
- UiLabel.DrawSelf 多行路径：3 行 × 行高放进 24px 高框 → startY 负偏移 + 每行 ty 钳制进 [y, y+h-lh] →
  三行基线全部塌缩进 24px 框内互相叠绘（与 f23-05 y=330..363、33px 高 179px 宽文本团完全一致）。
- 引擎多行路径可靠性差是既知根因（与 t21 空态 \n 行距、t22b 行内换行同族），唯一稳妥解=彻底不进多行路径。

### 修复（EngineMainShell.RowInfo 重写）
- 按 `\r`/`\n` 拆行（RemoveEmptyEntries），**每行一个独立 ClickableCard + 独立单行 UiLabel**：
  评级页 3 行 → 3 张行卡（「评级按 ACC 固定档位：」「SSS ≥100 · SS ≥98 · S ≥95 · A ≥90」「B ≥80 · C ≥70 · D <70」）。
- 标签：全卡宽（c.Width-24）、X=12、Y=8、Align=Left、**AutoShrinkFont + Ellipsis 双保险**（超长自动缩字号、
  缩到下限仍超则截尾省略号；单行简单路径 Ellipsize 有兜底 Clip 不越界）。
- 最长行 35 半角字符 @11pt ≈214px < 866 可用宽 → 实际不触发缩小/省略，逐字原样呈现。
- 其余 RowInfo 调用（判定/界面/存档/键位提示）均为单行文本，走同路径渲染结果不变（且提示行从 350px
  标签列放宽为全卡宽，只松不紧，无任何新压叠风险）。UiText 常量一字未改；legacy WinForms SettingsPanel
  评级段为 WinForms Label 多行（自带正确行距），不受影响。

## P1-1 编辑器右栏 7 页签标签相邻挤压

### 根因（像素取证）
- f23-14（2582×1550）右栏带宽 424 物理 px = 283 逻辑宽（424/1.5 DPI）——即 RightWidthOf(≈1208)=283 档。
- t20 的 ItemSize 38 定宽：7×38+内距 ≈274 逻辑 > 273 可用（283-8 折叠把手-2 边框）——**仅 1px 溢出**，
  FlatButtons+Fixed 定宽模式溢出即触发挤压/裁切（截图顶部只余最右 2 个标签文字与一个疑似滚动箭头残迹，
  其余 5 标签文字不可见）。

### 修复（ChartEditorPanel.BuildRightPanelShell）
- `SizeMode = TabSizeMode.Fixed + ItemSize 38` → **`TabSizeMode.Normal`（标签按文字自适应 AutoSize）**：
  7 标签按各自文字宽排布（合计 ≈237 逻辑宽 < 默认 300 档可用 290 与 t23 捕获 283 档可用 273），不再定宽挤占。
- `Multiline = true` 兜底：极窄右栏（最小 240 档，可用 ≈230 < 237）自动折成两行——不挤压、不出滚动箭头、无裁切。
- `Padding = new Point(2, 4)`：标签文字与按钮边缘 2px 呼吸间距。
- 判定线/Arcaea 页签按谱面模式物理增删（TabPages.Remove/Insert）与 Normal 模式无冲突（逐标签自适应）。
