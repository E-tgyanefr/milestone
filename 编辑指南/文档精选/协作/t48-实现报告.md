## 根因
- t47 修复在 Act 路径（AI 演示/联机/回环作曲/布局编辑器：壳被 Hide、游玩承载在**主窗体**）仍调用
  `_engineShell.UnhostContent()`——该函数 `_hostedContent==null` 时**直接 return**（不恢复场景/不置脏），
  t47 又补 `壳.Show()`——壳恢复显示但场景从未重建 → **黑屏**。

## 判据（ExitToLibrary 与 ExitToMenu 引擎分支同判据）
- **壳 Visible** ⇔ 游玩承载在壳内（t50 HostContent）→ `UnhostContent()` 回壳 UI 当前页（场景完整）；
- **壳 Hidden** ⇔ 游玩承载在主窗体（Act 路径）→ `ShowEngineShell()`（`Reopen()` 重建场景页 + 回引擎菜单）。

## 修复代码（两分支同款）
```csharp
if (!_legacyUi)
{
    if (_engineShell != null && !_engineShell.IsDisposed && _engineShell.Visible)
        _engineShell.UnhostContent();   // 壳内承载路径
    else ShowEngineShell();             // Act 路径：Reopen 回引擎菜单
}
else ShowLibrary();   // ExitToLibrary / ShowMainMenu(); // ExitToMenu
```
- 移除 t47 的「无条件 UnhostContent + this.Hide + 壳 Show」组合（壳隐藏时 UnhostContent 空 return 即黑屏源）；
- this.Hide() 由 ShowEngineShell/Reopen 内部完成（壳显示、主窗体隐藏——单窗口=1 保持）。

- 普通游玩退出（壳内承载）→ UnhostContent 回壳当前页；
