## 一、页 1：主菜单（旧版 vs 引擎）

整体结构相同：标题（Mile 白 + stone 蓝）→ 副标题 → 模式片行 → 玩家信息卡 →「开始游戏」→ 双列按钮网格 → 底部黄色快捷键提示。以下逐维度评级。

### 1.1 布局（对齐/位置/间距）——**明显差异**
| 项目 | 旧版（2538x1544） | 引擎（1280x800） | 评价 |
|---|---|---|---|
| 内容列宽度 | 约占画布宽度 39%（两侧留白大） | 约占画布宽度 55%（更满、更宽） | 明显差异 |
| 标题/副标题/模式片 | 从上到下依次排列，副标题在模式片**上方**，两者完全分离 | 副标题与模式片**重叠**：灰色副标题「全模式音游 · 10 种玩法引擎」被模式片行压住（z 序错误或 y 定位错误），文字从模式片缝隙中透出 | **明显差异（缺陷）** |
| 玩家信息区 | 深色圆角卡片：左侧圆形头像占位 + 「玩家」标题 + 一行统计（游玩 5 次 · 累计命中 68 音符 · 最高ACC 100.00% · 最佳连击 17x） | 该区域是一个**空面板**：只有暗色矩形残留，无头像、无标题、无任何统计内容 | **明显差异（内容缺失）** |

| 底部提示 | 金黄色 | 金黄色 | 一致 |

### 1.3 字体（字阶/字重/视觉大小）——**轻微差异**
- 标题：同类字体（Mile 白 / stone 蓝），字重与笔画形态几乎一致 → 一致。
- 副标题：灰色小字，字形、字重一致 → 一致。
- 按钮文字：同字形（雅黑系）同字重；引擎因画布 1280x800 而字相对更大、边距比例不同 → 轻微差异（视觉字号比例）。
- 统计行：旧版有 3 个小图标 + 数字；引擎无对应文本（缺失）→ 属布局问题 1.1。

### 1.4 控件形态（按钮/卡片/复选框/页签等）——**明显差异**
- 菜单按钮：圆角矩形条、无边框、圆角半径近似（旧版约 6-8px 视觉，引擎约 8-10px）→ 轻微差异。
- 「开始游戏」：旧版为「▶ + 文字」的蓝色大按钮；引擎同为蓝色大按钮、含白色 ▶，矩形圆角与辉光近似，但**宽度显著更宽** → 明显差异（宽度）。
- 图标占位：旧版与引擎**都用「□」占位符**当缺图标（旧版：联机/回放/曲库管理/校准/AI 演示/我的数据/打开日志/主题/退出 等；引擎：同样大面积 □+文字）——这一点是**一致的**（均为未完成态）；旧版仅在 编辑谱面/设置(齿轮)/引擎UI演示(✦)/关于 用真实图标；引擎在 编辑谱面/关于(i)/退出(✖)/开始游戏(▶) 用真实图标。差异：**引擎的「设置」菜单按钮用 □ 而旧版用齿轮**；选歌页头部用 □ 而设置页头部用齿轮 → 跨页图标策略不一致（P2）。
- 模式片：均为彩色圆角药丸形 → 形态一致（内容/颜色差异见 1.2）。
- 玩家卡片：旧版有内容，引擎为空面板 → 明显差异。

### 1.5 留白与整体观感——**明显差异**
- 旧版：顶部信息密集（标题→副标题→模式片→玩家卡→开始游戏），视觉重心聚中，两侧留白宽，整体"窄一点但完整"。
- 引擎：模式片与开始游戏之间有一大块**空面板空洞**（玩家卡未渲染），副标题被模式片遮挡，底部 退出 独行全宽；视觉重心下移、中上部出现明显"空缺感"；内容列更宽使留白结构改变。整体观感：**同设计语言、不同完成度**——骨架一样，但缺内容、有遮挡，明显未达旧版观感。

## 二、页 2：选歌页（旧版缺失，引擎自检）

旧版参照不可用（GPU 弹窗，见开头）。以下为引擎壳选歌页（1280x800，曲库为空态）的**自检**：

### 2.1 布局
- 页头：大标题「□ 选歌」（图标为 □ 占位）+ 左下「← 返回」深色小按钮；右上按钮组：［▶ 游玩当前］（蓝色高亮）、［编辑此谱面］、［随机］（深色）。
- 模式片行：［全部模式］蓝色高亮 + Mania/maimai/Phigros/Arcaea/Cytus/osu!standard/DOFAI/DOFAI/…，**行右侧溢出画面被截断**（最后一个模式片只剩一半）。
- 内容区：大标题「全部模式 · 0 难度」+ 下方灰色「曲库为空」+ 蓝色「请先「□ 打开谱面文件夹」指定曲库目录」。
- **缺陷**：右上三个按钮**相互重叠**——蓝色「游玩当前」按钮右缘覆盖「编辑此谱面」左缘，「编辑此谱面」与「随机」文字间距过近/粘连（So_topright.png 证据）。
- **缺陷**：「全部模式 · 0 难度」与「曲库为空」「请先…」三行**行距过紧，视觉上叠压**（曲库为空 灰字紧贴大标题下缘）。

### 2.2 配色
- 与本引擎主菜单同一套深色 + 蓝强调体系（底色、按钮蓝、高亮蓝一致）→ 内部风格一致。
- 模式片为深蓝灰底圆角片、白色文字，高亮为蓝色填充浅字 → 形态与配色自洽。
- 缺陷：与主菜单模式片的**16 进制取色不同**（这里是深色片而非彩色片），且此行也出现 **DOFAI 重复两次**。若旧版选歌页同为主菜单那套彩色片（未截到，无法确认），则此处为明显差异；需拿到旧版素材后复核。

### 2.3 字体
- 页头「选歌」为大号白字，与主菜单标题风格一致；「全部模式 · 0 难度」为大号白字；说明文字为灰色/蓝色小字。字阶层级清晰，无异常 → 内部一致。

### 2.4 控件形态
- 按钮与主菜单同款深灰圆角条；页头按钮组为小号圆角条；模式片为小圆角片；高亮蓝与主菜单「开始游戏」蓝一致。
- 无列表/卡片（空态），本页无复选框/数值框/页签可评。
- 缺陷：页头图标为 □ 占位（与设置页头部真实齿轮不一致，跨页不一致）。

### 2.5 留白与整体
- 顶部信息区紧凑，下半页整片为空（空态正常）；内容整体偏左上，右上部按钮组拥挤且重叠是最大观感问题。整体：**结构成立、细节未修**。

## 三、页 3：设置页（旧版缺失，引擎自检）

旧版参照不可用（同上，为 GPU 弹窗）。引擎壳设置页（1280x800）**自检**：

### 3.1 布局
- 页头：「⚙ 设置」**真实齿轮图标** + 大标题（与选歌页的 □ 占位不一致）＋「← 返回」。
- 主题卡行：3 张等宽卡片（深空蓝/极夜紫/晨光青），卡内主标题 + 子标签「▪玻璃质感」。
- 双列按钮网格：游戏/判定、分数/界面、评级/音效、皮肤/存档、键位（最后一行仅左列一项）→ 网格对齐、列间距均匀。
- 缺陷：**主题卡子标签「玻璃质感」与卡片底部渐变色带重叠**——「极夜紫」卡的紫色渐变带把紫字衬得几乎看不清（对比度不足）；「深空蓝」「晨光青」同样存在标签压渐变带的现象（Se_themes.png 证据）。文字位置紧贴卡片底缘，视觉被裁切感。

### 3.2 配色
- 深色底 + 三张主题预览卡（蓝/紫/青渐变 + 对应色方块标记），与主菜单/选歌页同一体系 → 内部一致。

### 3.3 字体
- 页头「设置」大号白字；卡片主标题中号白字；子标签小字彩色；按钮文字同主菜单。字阶一致、无异常。

- 主题卡：深色圆角矩形 + 底部渐变色带（"玻璃"质感视觉），彩色小方块 + 彩色子标签；无选中描边/高亮状态可见（三卡外观等同，**选中态不可辨**——需与旧版/设计稿确认是否应有选中样式）。
- 网格按钮：与主菜单相同的深灰圆角条，形态一致。

### 3.5 留白与整体
- 内容左对齐偏左上，右侧大空；顶部信息区整齐；三卡与网格间隔均匀。整体观感：**完成度高于选歌页（头部图标真实、无按钮重叠），但主题卡标签-渐变重叠是明显瑕疵**。

## 五、结论
